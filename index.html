No clear brief, no lesson.

Before a word is written, Mizasi pins down what this topic needs: the skill, the question format and the level. If the brief isn't clear, it stops.

  • Brief or stop
  • Never improvised

A team of agents writes it.

AI agents write the lesson together. Each has one job, and each kind of question has its own specialist.

  • One job each
  • Structured hand-offs
  • A specialist per question type

Code draws it and solves it.

The picture is built from geometry, not painted by an image model. The code that draws the shape also works out the answer, so the key can't be wrong.

  • Vector geometry
  • Exact arithmetic
  • Seeded and repeatable

Then it tries to cheat.

Can the question be answered without knowing the rule? Are two options the same? Each wrong option must be a mistake children really make. If not, the question is thrown away.

  • One right answer
  • No duplicate options
  • Not guessable

A second reader checks it.

An automated reviewer reads every lesson and looks at every picture. A new AI model only goes live when those scores say it is better.

  • Separate reviewer model
  • Sees the rendered picture
  • Gates model upgrades

Marked before a child sees it.

Only now does it reach the phone. Each child gets their own fresh set, and the answers stay on our server until the child has had a go.

  • Answers held on the server
  • Signed apps only
  • Next lesson prefetched

The AI writes. Code proves.

Two kinds of worker. Language models do what they are good at: explaining. Deterministic code does what must never be wrong: the answers.

  • 4 subjects
  • 1,449 topics
  • 3 platforms, one codebase

AI agents

  • Writers

    Explain the idea and the worked method in plain words, at the child's level.

  • Specialists

    Set the questions, with a different specialist for each kind of question.

  • Second reader

    A separate model that reads every lesson and looks at every picture before release.

Code engines

  • Solvers

    Work out every answer exactly. The AI is never the authority on what is right.

  • Picture engines

    Draw every figure, in 2D and 3D, from the same numbers the answer comes from.

  • Checks

    Throw out any question that is unclear, guessable or has more than one right answer.

  • Marker

    Marks each attempt on our server, never on the phone.

One lesson, start to finish.

Every run is recorded step by step. A draft that fails a check goes back to its specialist. Nothing skips the queue, and the next lesson is prepared before the child asks for it.

  1. Topic brief
  2. Writing agents
  3. Specialist, first draft
  4. Code engines
  5. Checks: rejected
  6. Specialist, second draft
  7. Code engines
  8. Checks: pass
  9. Second read
  10. Ready. Next lesson queued

Any model, same checks

Mizasi doesn't train its own AI model, and children's work is never used to train one. Quality comes from the brief, the code and the second read, so a better model can be put to work as soon as it passes.

  • No training on children
  • Upgrade when it passes

Runs like infrastructure.

Asynchronous by design
Lessons are queued and built by a private worker. The app never waits on a live model call.
Always one ahead
The next lesson is generated in the background while the child works on this one.
Keeps going under load
If an AI model is busy, the lesson is retried or handed to a backup.
Evaluation-gated upgrades
A new model goes live only after a full evaluation run scores it against the current one.
Fair-use limits
Limits for each child keep cost and load predictable.
Our apps only
The service only answers our own signed iOS, Android and web apps.
Locked-down connections
Connections and signing keys are locked down end to end.
Tested like a product
A large automated test suite, plus load tests of many children learning at once.
